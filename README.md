## 📊 Project Overview

Built an interactive Power BI dashboard to analyze airline revenue, bookings, and passenger trends across multiple airlines, routes, and airports.

### Project Highlights
- Revenue, profit & profit margin trends
- Booking status: Confirmed vs Cancelled
- Passenger trends by gender, day & ticket class
- Revenue by airline, airport, payment mode & route
- Month-to-Date (MTD), Quarter-to-Date (QTD) & Year-to-Date (YTD) revenue tracking

---

## 🗂️ Data Model

This project uses a Star and Snowflake Schema to connect related tables, keeping the data organized, reducing duplication, and enabling accurate reporting in Power BI.
